# KATALOG GAYA, PALET WARNA & ATURAN PENALARAN INDUSTRI (UI UX PRO MAX)

Panduan operasional mendalam untuk memilih kombinasi gaya antarmuka, warna, dan tipografi berbasis kategori produk nyata.

---

## 1. Katalog Gaya Desain Utama (Kategori Pilihan)

### Gaya 1: Soft UI Evolution (Modern SaaS & Layanan Premium)
- **Karakteristik**: Bayangan bertingkat halus (*multi-layered soft shadows*), sudut membulat organik (border-radius: 12px sampai 16px), latar belakang hangat, kontras tajam.
- **Cocok Untuk**: B2B SaaS, manajemen proyek, aplikasi kesehatan/wellness, e-commerce modern.
- **Warna Ideal**: Latar belakang putih gading/warm-white (`#F8FAFC` atau `#FDFBF7`), aksen biru korporat atau sage green, teks arang (`#1E293B`).

### Gaya 2: Bento Box Grid (Dashboard, Portofolio & Fitur Produk)
- **Karakteristik**: Pembagian area modular terkotak-kotak dengan sudut membulat, kartu informasi mandiri, visualisasi metrik ringkas.
- **Cocok Untuk**: Landing page fitur teknologi, dashboard analisis, portofolio desainer.
- **Warna Ideal**: Latar abu-abu terang bertingkat, batas tipis 1px (`#E2E8F0`), kartu putih cerah.

### Gaya 3: Dark Mode OLED (Platform Koding, Kripto & Hiburan)
- **Karakteristik**: Latar hitam pekat (`#0B0F17` atau `#09090B`), kartu abu-abu gelap terangkat (`#18181B`), aksen warna berpendar fungsional, kontras teks putih murni (`#F8FAFC`).
- **Cocok Untuk**: Terminal pengembang, platform bursa kripto, aplikasi streaming video, IDE.

### Gaya 4: Modern Swiss & Extreme Minimalism (Finansial, Berita & Editorial)
- **Karakteristik**: Tipografi tegas sans-serif, spasi putih sangat lapang, garis pembatas tegas 1px hitam/abu-abu, minim dekorasi visual.
- **Cocok Untuk**: Perbankan digital, firma hukum, publikasi riset, platform asuransi.

| **B2B SaaS / Enterprise** | Bento Grid / Soft UI | Slate (#0F172A), Indigo (#4F46E5), Latar Netral (#F8FAFC) | Geist Sans / Inter | Animasi lambat > 500ms, font display dekoratif |

| **E-Commerce & Belanja** | Content-First Dynamic | Netral Monokrom dengan aksen Jingga/Kuning Emas (#D97706) | Plus Jakarta Sans / Outfit | Tombol CTA samar, popup berlapis-lapis |
| **Pengembang & DevOps** | Dark Mode OLED / Terminal UI | Hitam Pekat (#09090B), Aksen Hijau Neon (#22C55E) atau Cyan | JetBrains Mono / Fira Code | Elemen dekoratif tanpa shortcut keyboard |

## 3. Formula Pasangan Tipografi (Font Pairings)

1. **Modern Tech & SaaS**: `Inter` (Heading) + `Inter` (Body) dengan variasi bobot (Semibold 600 untuk judul, Regular 400 untuk teks). Alternatif modern: `Geist Sans` atau `Plus Jakarta Sans`.
2. **Editorial & Finansial Mewah**: `Cormorant Garamond` (Heading) + `Montserrat` atau `Plus Jakarta Sans` (Body).
3. **Produk Berorientasi Data**: `Space Grotesk` (Heading & Angka Metrik) + `Inter` (Body).
4. **Developer Tools**: `Fira Code` atau `JetBrains Mono` (Judul & Snippet) + `Inter` (Body).
