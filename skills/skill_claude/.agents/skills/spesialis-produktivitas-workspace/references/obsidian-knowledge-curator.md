# Obsidian Knowledge Curator

## When to use this skill
Whenever the user provides an article, tutorial, or prompt to extract knowledge and save it into their Obsidian vault (`E:\BELAJAR BANGET\SKILL BELAJAR`).

## Rules & Standards
1. **Frontmatter**: Every note must begin with YAML frontmatter containing:
   - `title`: Note title
   - `tags`: Relevant tags (e.g., `#MachineLearning`, `#Leadership`)
   - `created`: YYYY-MM-DD
   - `type`: `concept`, `paper`, `guide`, `summary`
2. **Structure**:
   - Give a brief TL;DR at the top.
   - Break down core principles logically.
   - Highlight actionable insights or "Key Takeaways".
3. **MOC Linking**: Determine which of the 7 main domains the note belongs to:
   - Data Science
   - Machine Learning
   - Personal Development
   - SYSTEM ANALYST
   - Finance
   - Relationship
   - FILSAFAT
   Mention how it links to the `🏠 Master Index (MOC).md` and suggest exactly where the file should be saved (Absolute path).
4. **Style**: Use bullet points, callouts (e.g., `> [!info]`), and clear hierarchical headers.
