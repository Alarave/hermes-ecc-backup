# /spesialis-skills

Alias komando cepat untuk memanggil **specialist-skill-architect**.

## Penggunaan

```bash
/spesialis-skills explain <nama-skill>
/spesialis-skills create <nama-skill-baru>
/spesialis-skills extend <nama-skill>
/spesialis-skills improve <nama-skill>
/spesialis-skills combine <skill-a> <skill-b>
```

Mengelola siklus hidup skill AI: penemuan kebutuhan, riset SOTA GitHub, pembobotan 7 strategi rekayasa, penjaminan mutu 5 Gates (G0-G4), dan audit linter skor 100/100.
