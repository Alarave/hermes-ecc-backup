# /spesialis-copywriter

Alias komando cepat untuk memanggil **spesialis-copywriter**.

## Penggunaan

```bash
/spesialis-copywriter landing-page [nama-produk / penawaran]
/spesialis-copywriter ads [platform: meta / google / tiktok]
/spesialis-copywriter email [tujuan: welcome / nurture / sales]
/spesialis-copywriter microcopy [komponen: button / error / modal]
/spesialis-copywriter slide-client [nama-produk / penawaran-pitch-deck]
/spesialis-copywriter slide-defense [judul-skripsi / tesis-akademik]
/spesialis-copywriter audit [teks-yang-akan-diaudit]
```

Menyusun naskah pemasaran bernilai konversi tinggi: bebas dari kata klise robotik AI slop, mematuhi tata bahasa baku EYD V dan KBBI, menerapkan kerangka kerja persuasi ilmiah (AIDA, PAS, BAB, 4P, FAB), serta aman dari klaim berlebihan sesuai Etika Pariwara Indonesia.
