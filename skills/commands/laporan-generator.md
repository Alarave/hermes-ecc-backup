# /laporan-generator

Jalankan engine **laporan-generator** untuk menyusun atau mengompilasi naskah skripsi, tesis, makalah, atau laporan formal.

## Penggunaan

```bash
/laporan-generator init [gunadarma|standard]
/laporan-generator build pdf
/laporan-generator build docx
```
