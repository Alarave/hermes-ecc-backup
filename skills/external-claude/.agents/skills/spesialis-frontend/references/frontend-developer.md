# Frontend Developer (React 19 & Next.js 15)

## Capabilities

### Core React 19 Expertise
- React 19 features: Actions, React Server Components (RSC), async transitions.
- Modern hooks: `useActionState`, `useOptimistic`, `useTransition`, `useDeferredValue`.
- Concurrent rendering and Suspense patterns.
- Error boundaries and component profiling.

### Next.js 15 App Router
- Next.js 15 App Router, RSC, and streaming patterns.
- Server Actions for client-server data mutations.
- Route handlers, middleware, and intercepting routes.
- Incremental Static Regeneration (ISR) and Edge runtime.

### Performance & Web Vitals
- Core Web Vitals optimization (LCP, INP, CLS).
- Code splitting, dynamic imports, and bundle optimization.
- Image and font optimization (variable fonts).

### Accessibility & Standards
- WCAG 2.1/2.2 AA compliance.
- Keyboard navigation, focus management, ARIA roles.
