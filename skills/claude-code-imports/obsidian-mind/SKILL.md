# Obsidian Mind Skill

Obsidian Mind is a personal vault system and external brain for work notes, decisions, performance tracking, and structured markdown knowledge management.

## Capabilities & Sub-Skills

This skill repository provides the full Obsidian Mind operating model and 8 specialized sub-skills:

1. **obsidian-markdown**: Obsidian-flavored markdown syntax (wikilinks `[[link]]`, callouts, embeds, frontmatter metadata).
2. **obsidian-cli**: CLI integration for interacting with live Obsidian instances.
3. **obsidian-bases**: Data bases and dynamic views (`.base` files) for structured navigation and filters.
4. **json-canvas**: Creating and editing `.canvas` files for visual diagrams and maps.
5. **mermaid-visualizer**: Creating Mermaid diagrams and flowcharts in Obsidian.
6. **defuddle**: Web parsing and clean markdown extraction (`defuddle parse <url> --md`).
7. **qmd**: Fast semantic search across the vault using QMD index.
8. **excalidraw-diagram**: Hand-drawn visual diagrams and Excalidraw integration.
