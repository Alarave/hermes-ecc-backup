# /asep

Panggil **Asep** (spesialis-skills) untuk rekayasa siklus hidup skill AI.

## Penggunaan

```bash
/asep explain <nama-skill>
/asep create <nama-skill-baru>
/asep extend <nama-skill>
/asep improve <nama-skill>
/asep combine <skill-a> <skill-b>
```

Mengelola siklus hidup skill AI: riset ekosistem GitHub, ekstraksi dokumen, TDD instruksi anti-loophole, audit linter 100/100, dan arsitektur RCCO.
