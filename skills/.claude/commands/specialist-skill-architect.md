# /specialist-skill-architect

Jalankan engine **specialist-skill-architect** untuk merancang, menjelaskan, memperluas, mengaudit, atau menggabungkan specialist skills AI.

## Penggunaan

```bash
/specialist-skill-architect explain <nama-skill>
/specialist-skill-architect create <nama-skill-baru>
/specialist-skill-architect extend <nama-skill>
/specialist-skill-architect improve <nama-skill>
/specialist-skill-architect combine <skill-a> <skill-b>
```

## Mode Operasional

1. **Mode A (EXPLAIN)**: Membedah arsitektur, peran, batasan, alur kerja, dan potensi kegagalan skill yang ada.
2. **Mode B (CREATE)**: Membangun skill baru dari nol dengan struktur RCCO modular 12 langkah.
3. **Mode C (EXTEND)**: Menambahkan fitur atau modul referensi baru dengan jaminan backward compatibility.
4. **Mode D (IMPROVE)**: Audit mutu, refactoring instruksi, pembersihan slop, dan penggabungan skill.
